# Submission checklist

Included: final report PDF and editable Word, final card UI, extraction/date code, frozen prompt, replacement 40 PDFs and source text/HTML, actual 34 development PDFs, saved predictions, separated references/evaluations, README, product architecture and target/reached metrics.

The main dataset is the replacement 40: 15 retained originals plus 10 earlier additions plus 15 recent additions. Earlier evaluation evidence remains separately labelled. This selected final set is not a new blind hold-out. The final report describes the completed historical evaluation and its limitations.

Only required item not yet supplied: your face-and-screen demo video. Add it under video/ before submission. No demo guide is included.

The public dashboard URL is in README.md and docs/PUBLISHING.md. Upload this folder using the course submission instructions. This package has not been submitted externally or uploaded to a GitHub repository.

To reproduce the packaged checks, run the offline commands in README.md. No API key is needed. Fresh extraction is optional and saved separately.
